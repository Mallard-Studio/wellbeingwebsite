Delete My Data

Request erasure of the data linked to your Digital Wellbeing App install

Before you submit

We do not ask for your name or email. The only thing that links data to you is your User ID, so we need it to find and erase your records.

  • Open the app and go to the Profile tab.
  • Your ID is shown at the bottom of the screen, in the form GW-XXXX-XXXX.
  • Tap the copy button next to it, then paste it below.

Your ID is tied to a single device. If you installed the app on more than one device, submit one request per device — each has its own ID.

Request deletion

Found in the app under Profile.
Not required, but it helps us improve.
Request received.
We will erase the data for that ID within 30 days, except where the law requires us to keep it. You can keep using the app — a new ID is created if you check in again.

What happens next

  • We locate the records stored against the ID you submitted.
  • Your check-ins, usage records and profile data for that install are erased within 30 days.
  • Deletion is permanent. We cannot restore the data afterwards.
  • Uninstalling the app on its own does not erase data already stored — this request does.

Prefer to email us?

Send your User ID to info@digitalwellbeingapp.com and we will process it the same way.
